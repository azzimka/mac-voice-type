# 🎙️ Mac Voice Type

> **Сверхбыстрая нативная диктовка текста для macOS по двойному нажатию ⌘ с искусственным интеллектом Groq (Whisper + Llama 3.3).**

Встроенная диктовка macOS часто ошибается, долго думает и плохо справляется со смешанной речью. **Mac Voice Type** решает эту проблему:
1. Вы нажимаете **дважды клавишу `Command` (⌘)** в любом приложении.
2. Внизу экрана всплывает элегантная стеклянная капсула **Dynamic Island** с живой звуковой волной.
3. Вы говорите фразу на русском или английском.
4. Повторное нажатие **`Command`** отправляет аудио в сверхбыстрый **Groq Whisper** (~200 мс) и аккуратно исправляет опечатки и знаки препинания через **Groq Llama 3.3** (без изменения ваших слов и смысла).
5. Текст мгновенно печатается в активное поле ввода, а ваш предыдущий буфер обмена остается нетронутым!

## ✨ Ключевые возможности

* ⚡ **Сверхбыстрый отклик:** Скорость расшифровки ~200–300 мс благодаря LPU-чипам Groq.
* 🧠 **ИИ-корректор грамматики:** Исправляет орфографию, пропущенные запятые и заглавные буквы, строго сохраняя авторские слова, сленг и стиль.
* 💎 **Apple-дизайн:** Плавающий HUD из матового стекла (`.ultraThinMaterial`) с адаптивной звуковой волной, реагирующей на громкость микрофона.
* 🛡️ **Приватность и безопасность:**
  * Groq API Key хранится в системной связке ключей **macOS Keychain Services**.
  * Голос пишется во временный буфер и **моментально удаляется** сразу после расшифровки. Никаких аудиоархивов на диске.
* 📋 **Умный буфер обмена:** Приложение восстанавливает скопированный вами ранее текст или ссылки через 400 мс после вставки.
* 🪶 **Экстремальная легковесность:** Размер всего **~530 КБ**, 0% нагрузки на процессор в режиме ожидания.

## 🚀 Установка и запуск

### Требования
* Mac на базе процессоров Apple Silicon (M1, M2, M3, M4) или Intel.
* macOS 14.0 (Sonoma) или новее.
* Бесплатный API-ключ от [console.groq.com](https://console.groq.com/keys).

### Быстрая сборка из исходников

```bash
# 1. Склонируйте репозиторий
git clone https://github.com/YOUR_USERNAME/mac-voice-type.git
cd mac-voice-type

# 2. Запустите скрипт сборки
./build_app.sh

# 3. Запустите приложение
open MacVoiceType.app
```

Или переместите `MacVoiceType.app` в папку `/Applications`.

## ⚙️ Первоначальная настройка

1. При первом запуске в строке меню (возле часов) появится иконка микрофона 🎙️.
2. Нажмите на иконку ➔ **Настройки...** (`⌘,`).
3. Вставьте ваш **Groq API Key** и нажмите **Сохранить**.
4. В разделе **Системные разрешения** убедитесь, что приложению выданы права:
   * **Микрофон** (для захвата речи).
   * **Универсальный доступ (Accessibility)** (для перехвата двойного нажатия ⌘ и автоматической вставки через ⌘+V).
