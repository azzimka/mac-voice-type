## ⚡ Как пользоваться

1. **[Скачайте `Froggy.dmg`](https://github.com/azzimka/mac-voice-type/raw/main/Froggy.dmg)** → перетащите в **Программы**.
2. Откройте → вставьте бесплатный API-ключ от [console.groq.com](https://console.groq.com/keys) → **Сохранить**.
3. Разрешите **Микрофон** и **Универсальный доступ**.

**Готово!** Дважды нажмите `⌘` → говорите → `⌘` → текст вставлен!

---

## 💎 Особенности

* ⚡ **~200 мс** — молниеносная расшифровка на Groq LPU
* ✍️ **ИИ-корректор** — пунктуация и орфография без изменения ваших слов
* 📋 **Умный буфер** — ваш скопированный текст не затирается
* 🛡️ **Приватность** — ключ в Apple Keychain, аудио удаляется мгновенно

### Требования
macOS 14+ • Apple Silicon или Intel
