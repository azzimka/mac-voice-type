## ⚡ Быстрый старт

1. **[Скачайте `Froggy.dmg`](https://github.com/azzimka/mac-voice-type/raw/main/Froggy.dmg)**.
2. Откройте файл и перетащите иконку **Froggy** в папку **Applications** (Программы).
3. **Если macOS сообщает, что приложение не удаётся открыть:**  
   Откройте Терминал, вставьте эту команду и нажмите Enter:
   ```bash
   xattr -cr /Applications/Froggy.app
   ```
   *(Либо перейдите в Системные настройки → Конфиденциальность и безопасность → нажмите «Подтвердить вход»).*
4. Запустите Froggy и укажите бесплатный API-ключ от [console.groq.com/keys](https://console.groq.com/keys) → нажмите **Сохранить**.
5. Включите разрешения на **Микрофон** и **Универсальный доступ**.

---

## 🎮 Как пользоваться

1. Поставьте курсор в любое текстовое поле (Telegram, браузер, VS Code, Заметки и т.д.).
2. **Быстро дважды нажмите `⌘ Command`** — внизу появится плавающая капсула со звуковой волной.
3. Говорите фразу на любом языке.
4. **Нажмите `⌘ Command` один раз** — готовый, исправленный текст мгновенно вставится!

## 💎 Особенности

* ⚡ **~200 мс** — сверхбыстрая расшифровка на чипах Groq LPU.
* 🌐 **Мультиязычность и Code-switching** — свободно говорите на **узбекском** (латиница/кириллица), **русском**, **английском** или смешивайте их в одной фразе.
* ✍️ **Умный ИИ-корректор** — Llama 3.3 аккуратно расставляет точки, запятые и исправляет опечатки, **не искажая ваши слова и сленг**.
* 🌊 **Apple-grade анимация** — шелковистая плавная звуковая волна с частотой ProMotion до 120 Гц.
* 🛡️ **Приватность** — ключ сохраняется локально на вашем Mac, аудиозаписи удаляются сразу после транскрибации.
